# 📘 Machine Learning Algorithms and Concepts

A collection of Machine Learning, Data Analysis, Regression, Classification, Clustering, NLP, and Linear Algebra notebooks implemented using Python and Jupyter Notebook for practical learning and experimentation.

---

## 📂 Repository Contents

| Notebook | Description |
|----------|-------------|
| `simple_linear_regression.ipynb` | Simple Linear Regression implementation |
| `MultipleRegression.ipynb` | Multiple Regression model implementation |
| `LogisticRegression.ipynb` | Logistic Regression for classification |
| `SupportVectorRegression.ipynb` | Support Vector Regression (SVR) |
| `RandomForestRegression.ipynb` | Random Forest Regression implementation |
| `RandomForestClassification.ipynb` | Random Forest Classification model |
| `SVM.ipynb` | Support Vector Machine algorithm |
| `KMeansClustering.ipynb` | K-Means clustering implementation |
| `DimensionalityReduction.ipynb` | Feature reduction techniques |
| `ExploratoryDataAnalysis.ipynb` | Data analysis and visualization |
| `DataPreprocessing.ipynb` | Data cleaning and preprocessing |
| `DataVisualization.ipynb` | Visualization techniques using Python |
| `scatterplot.ipynb` | Scatter plot implementation |
| `WhiskerBoxPlot.ipynb` | Box plot and statistical visualization |
| `MNIST.ipynb` | MNIST handwritten digit dataset implementation |
| `TensorBoard_MNIST.ipynb` | TensorBoard visualization with MNIST |
| `NLP.ipynb` | Natural Language Processing basics |
| `TimeSeries.ipynb` | Time Series analysis concepts |
| `Uncertainty.ipynb` | Probability and uncertainty concepts |
| `Linear_Algebra_in_Python.ipynb` | Linear Algebra operations in Python |
